The core is a standard [Agent Skills](https://agentskills.io/specification) folder: `SKILL.md` uses only the six spec fields, so the same files serve every platform. Only the install location and the way the skill is activated differ.

**A platform is listed as verified only when the real assistant was seen activating the skill**, not when files were copied. Conventions were checked against official documentation on 2026-10-12.

## Per platform

| | Claude Code | OpenAI Codex | Cursor 2.4+ |
|---|---|---|---|
| User install | `~/.claude/skills` | `~/.agents/skills` | `~/.cursor/skills` (also reads `~/.agents`, `~/.claude`, `~/.codex`) |
| Project install | `.claude/skills` | `.agents/skills` | `.cursor/skills` or `.agents/skills` |
| Explicit invocation | `/rack-cabling-designer` | `$rack-cabling-designer` | `/rack-cabling-designer` |
| Implicit invocation | By description | By description | By description |
| Discovery after install | Live (`/reload-skills` if the folder did not exist) | Next turn; restart if missing | At startup; reload the window |
| Running `rackcab` | Through the Bash tool, subject to permissions | Shell in the `workspace-write` sandbox; no network needed | Agent terminal, under the Run Mode |
| Platform-specific files | none | `agents/openai.yaml` (UI metadata, ignored elsewhere) | none |

All platforms need **Node.js 22.18+** on the PATH for the toolkit. Without it, the instructions and references still work and the assistant reports the rule checks as not executed.

## Known limitations

- **Duplicates.** Cursor also reads the Claude Code and Codex folders, so installing for several assistants can make one see two copies. The installer shares folders where it can, shows which assistant sees which copy, and warns. Keep copies on the same version.
- **Codex legacy folder.** Copies in `~/.codex/skills` are still loaded and appear twice; `--verify` warns about them. The installer never writes there.
- **Agent-driven installs in Codex.** Codex's sandbox protects `.agents/`, so asking Codex itself to run the installer into `.agents/skills` needs approval. Running the installer in your own terminal is unaffected.
- **Outputs are files.** `elevation.html` opens in a browser on every platform; it is not rendered inline in the chat.
