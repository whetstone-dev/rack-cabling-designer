This walkthrough takes you from one request to a validated rack with its elevation, schedule and BOM. It assumes the skill is [installed](../installation/) and Node.js 22.18+ is available.

<Steps>
  <Step title="Describe the rack">
    Open your assistant in a project folder and ask in plain language. Include the numbers you know; the skill fills the rest from its references and tells you what it assumed.

    <PromptRef id="office-cabinet" />
  </Step>

  <Step title="Let it build the model">
    The assistant writes a model such as `racks/office.rack.json` in your project (never inside the skill folder). It starts from `rackcab init` or one of the examples, and uses generic catalog types where you did not give a datasheet:

    ```bash
    node "<skill-dir>/scripts/rackcab.ts" init racks/office.rack.json
    ```
  </Step>

  <Step title="Validate and fix">
    The assistant runs every rule and fixes the model until there are no errors, explaining each fix in terms of the rule:

    ```console
    · info    RCD-AIR-BLANKING       Rack "R01" has 39 open unit(s) on the cold face (U1-U39); fit blanking panels to stop hot-air recirculation.

    PASS: 0 error(s), 0 warning(s), 1 info · 1 rack(s), 3 device(s), 1 cable(s), 1 channel(s)
    ```

    Info findings are advice; warnings deserve a look; errors block the build.
  </Step>

  <Step title="Generate the deliverables">
    With a passing model, `build` writes seven files:

    ```bash
    node "<skill-dir>/scripts/rackcab.ts" build racks/office.rack.json -o racks/office-docs
    ```

    ```tree
    racks/office-docs/
    ├── elevation.html        # front and rear views of every rack
    ├── README.md             # design document
    ├── cable-schedule.csv    # every cable by channel
    ├── labels.csv            # two labels per cable
    ├── bom.csv               # bill of materials
    ├── power.md              # power budget
    └── report.json           # findings and channels
    ```
  </Step>

  <Step title="Review and iterate">
    Open `elevation.html` in a browser and ask for changes in plain language. The assistant edits the model and rebuilds; it never patches generated files.

    <Prompt>Move the router above the firewall, add a second cable manager under the switch and rebuild.</Prompt>
  </Step>
</Steps>
